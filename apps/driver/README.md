# Жолоочийн апп (төлөвлөгдсөн)

React Native (Expo) дээр хийгдэнэ. Үндсэн боломжууд:

- Утасны дугаар + SMS кодоор нэвтрэх
- Онлайн / офлайн төлөв, байршлаа илгээх
- Оноогдсон хүргэлтүүдийн жагсаалт, газрын зураг дээр чиглэл
- Статус шинэчлэх: Барааг авсан → Хүргэсэн / Амжилтгүй (шалтгаан)
- Хүргэсний баталгаа (зураг), цуглуулсан бэлэн мөнгө бүртгэх
- Өдрийн тооцоо: цуглуулсан COD, оффист тушаах дүн

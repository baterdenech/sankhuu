# Coupang (m.coupang.com) ↔ Sankhuu худалдан авагчийн апп: элемент бүрийн харьцуулалт

Coupang-ийн мобайл сайт/аппын элемент бүрийг манай `app/(shop)/`-той харьцуулж, ямар шийдлийг авсан, юуг санаатай авалгүй орхисныг энд тэмдэглэв.
Дараа нь дизайн засахдаа энэ жагсаалтаас үргэлжлүүлнэ.

Тэмдэглэгээ: ✅ адил/авсан · 🔁 өөрчилж авсан · ➖ санаатай орхисон

## Дараагийн боломжит алхам
- Дуртай бараа (♡) ба картан дээрх сагсны товч: худалдан авагчийн бүртгэл орсны дараа
- Хайлтын шүүлтүүр (үнийн хязгаар, зөвхөн бэлэн, дэлгүүрээр) ба эрэлттэй хайлтын үгс
- Дэд ангилал орвол ангиллын хуудсыг Coupang шиг 2 багана болгох

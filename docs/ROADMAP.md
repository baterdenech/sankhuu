# Замын зураг

## 1-р шат: Худалдагчийн хэрэгсэл + өөрийн хүргэлт  ← одоо

Зорилго: худалдагч бараагаа хялбар бүртгэж, захиалгаа нэг газраас удирдаж, хүргэлтээ Sankhuu-д даатгах.
Орлого: хүргэлт бүрийн хөлс.

**Урсгал**
1. Худалдан авагч апп/веб дээрээс захиалга өгнө (эсвэл худалдагч утсаар ирсэн захиалгыг гараар бүртгэнэ).
2. Системд `Delivery` (PENDING) автоматаар үүснэ.
3. Диспетчер хүргэлтийг жолоочид онооно (ASSIGNED).
4. Жолооч барааг дэлгүүрээс авна (PICKED_UP), хүргэнэ (DELIVERED) эсвэл амжилтгүй болгоно (FAILED), бэлэн мөнгийг цуглуулна.
5. Жолооч өдрийн эцэст мөнгөө оффист тушаана (`CashHandover`).
6. Sankhuu худалдагчид COD-оос хүргэлтийн хөлсийг хасаад шилжүүлнэ (`Settlement`).

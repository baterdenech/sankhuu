# Замын зураг

## 1-р шат: Худалдагчийн хэрэгсэл + өөрийн хүргэлт  ← одоо

Зорилго: FB худалдагчид захиалгаа нэг газраас бүртгэж, хүргэлтээ Sankhuu-д даатгах.
Орлого: хүргэлт бүрийн хөлс.

**Урсгал**
1. Худалдагч Messenger-ээр ирсэн захиалгыг бүртгэнэ (худалдан авагч, хаяг, бараа, COD дүн).
2. Системд `Delivery` (PENDING) автоматаар үүснэ.
3. Диспетчер хүргэлтийг жолоочид онооно (ASSIGNED).
4. Жолооч барааг дэлгүүрээс авна (PICKED_UP), хүргэнэ (DELIVERED) эсвэл амжилтгүй болгоно (FAILED), бэлэн мөнгийг цуглуулна.
5. Жолооч өдрийн эцэст мөнгөө оффист тушаана (`CashHandover`).
6. Sankhuu худалдагчид COD-оос хүргэлтийн хөлсийг хасаад шилжүүлнэ (`Settlement`).

**Даалгавар**
- [x] Monorepo бүтэц, мэдээллийн сангийн схем
- [x] Веб самбарын үндсэн хуудсууд
- [ ] Утас + SMS OTP нэвтрэлт (SMS үйлчилгээ үзүүлэгч сонгох)
- [ ] Дэлгүүр бүртгэх, барааг авах хаяг тохируулах
- [ ] Бараа CRUD (зураг upload)
- [ ] Захиалга бүртгэх форм → хүргэлт автоматаар үүсэх
- [ ] Хүргэлтийн үнийн тооцоо (дүүрэг / зайгаар)
- [ ] Диспетчерийн самбар: хүргэлтийг жолоочид оноох, газрын зураг
- [ ] Жолоочийн апп (Expo)
- [ ] Худалдан авагчид SMS-ээр хүргэлтийн статус мэдэгдэх
- [ ] COD тушаалт болон худалдагчийн тооцооны тайлан
